## Why External Data is still stale

Zhinu's **Heart** is its message bus (an MQTT broker called moquette). The PulseWatcher drops each incoming pulse on it, and Zhinu listens for those pulses.

The Heart has a memory leak. In this moquette version, the code that watches each message has to hand the message's memory back when it's done. Ours never did, so every pulse (about 330 KB each) leaked. After a couple of hours the Heart has no room left to send a big pulse. So when anyone subscribes to pulses (`OrganismUpdate`), it accepts and then hangs up within half a second. Small messages still get through, which is why nothing else looked wrong.

How I checked:
- A small probe on chilhuacle showed the hang-up.
- Locally, with the same broker and memory capped at 24 MB, I replayed Tlaloc's real pulse 120 times. Without the fix the broker jams; with it, all three listeners get every message.

On top of that, Zhinu's listener connected only once and never reconnected. So any Heart restart cut it off for good.

**The home Heart has the same leak** (`heart/PublisherListener.java`, same broker version), so I fixed it there too.

**Cleotilde side:**
- Every 10 seconds Cleotilde opens that letter box over SFTP, the same secure file copy it already uses for its pulse.
- For each new ring it asks the board whether the code is right.
- It writes the answer back next to the letter box, in `Cleotilde.delivered.json`. The page checks every 5 seconds, so you see **"code valid"** or **"code refused"** about 10–20 seconds after ringing.
- For now a valid ring is only shown on the board's OLED (page 4). Opening FACTORY2 and other services comes with the next piece, Network Rules.

**Safety rules on Cleotilde:**
- A ring older than 3 minutes is marked "expired" without asking the board, so old or copied rings can't use up your 5 wrong codes.
- If the board doesn't answer (a USB glitch), Cleotilde asks again 10 s later instead of calling the code wrong.
- Cleotilde remembers answered rings, so a restart never asks the board twice about the same code.
